Скрипт-сборщик для кабинета Avito

Работает локально в открытом браузере для любого из ваших профилей

  1. Откройте нужный профиль Avito → Мои объявления (вкладку «Активные»).
  2. Нажмите F12 (или Ctrl+Shift+I) → выберите вкладку Console (Консоль).
  3. Скопируйте код ниже, вставьте его в консоль и нажмите Enter.
  4. Скрипт соберёт объявления и скопирует их в буфер обмена — вставьте их в окно слева и выберите профиль («Авито 1» или «Влада»)!
(() => {
  const items = [];
  document.querySelectorAll('[data-marker*="item"]').forEach(el => {
    const titleEl = el.querySelector('a[data-marker*="title"], h3, [class*="title"]');
    const dateEl = el.querySelector('[data-marker*="date"], [class*="date"]');
    if (titleEl && titleEl.innerText.trim().length > 2) {
      items.push({
        date: new Intl.DateTimeFormat('en-CA', { timeZone: 'Europe/Moscow' }).format(new Date()),
        rawDate: dateEl ? dateEl.innerText.trim() : '',
        title: titleEl.innerText.trim(),
        cat1: '', cat2: '', cat3: '',
        type: 'Новое объявление'
      });
    }
  });
  const unique = Array.from(new Map(items.map(i => [i.title, i])).values());
  copy(JSON.stringify(unique, null, 2));
  alert('Собрано объявлений: ' + unique.length + '. Данные скопированы в буфер обмена!');
})();

📱 Как установить приложение на экран

🤖 Android (Google Chrome):

Нажмите кнопку «📲 Установить» в шапке (если она видна) или откройте меню браузера ⋮ (три точки в правом верхнем углу) → выберите «Добавить на гл. экран» / «Установить приложение».

🍎 iPhone / iPad (Safari):

Откройте страницу в Safari → нажмите кнопку «Поделиться» (квадрат со стрелкой вверх внизу экрана) → пролистайте вниз и выберите «На экран „Домой“» → нажмите «Добавить».
